# Sound effects: licence and provenance

Every file in `apps/game/assets/sounds/` is generated by `apps/game/scripts/make-sounds.py` from noise, sine tones, filters and envelopes. Nothing is sampled, recorded or downloaded, so there is no third-party licence to track. The files and the script are released as CC0 with the rest of the project's own assets.

To change a sound, edit its recipe in the script and run `python3 scripts/make-sounds.py` (needs numpy and scipy). Levels are applied in the app (`LEVEL_GAIN`), so every file is normalised to the same peak. These are synthetic stand-ins: they have not been auditioned, and a recorded foley set could replace them file for file with no code change.

The one runtime dependency is `expo-audio` (MIT).
